# 📊 Project 2: Website Traffic Analysis

# Traffic-Analysis
Analyzed 9,439 website traffic records using Python  and Power BI to uncover page performance insights,  CTR trends, bounce rates, and segment-wise engagement  metrics with an interactive dashboard.

## Overview
Analysis of website traffic data using
Python and Power BI to extract business insights
from page performance metrics.

## Tools Used
| Tool | Purpose |
|------|---------|
| Python | Data cleaning & analysis |
| Pandas | Data manipulation |
| Matplotlib/Seaborn | Visualizations |
| Jupyter Notebook | Development environment |
| Power BI | Interactive dashboard |

## Dataset
- Source: Refer attached file
- Records: 9,439 rows | 19 columns
- Key columns: Clicks, Impressions, BounceRate,
  Segments, Position, ViewDepth, Inlinks

## Project Objectives
- [x] Analyze traffic dataset (sessions, bounce rate)
- [x] Identify top traffic sources by segment
- [x] Evaluate user engagement metrics
- [x] Track conversion rates (CTR)
- [x] Identify high & low performing pages
- [x] Build Power BI dashboard

## Key Findings
- Product segment → highest clicks (26K)
- Top 10 position → best CTR (2.9%)
- 51.9% pages → low bounce rate (good!)
- Overall CTR → 2.18%
- Total Inlinks → 2.20M

## Dashboard Pages
